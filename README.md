# 開拓の島 モフルジム

島に道とジムを建てて、モンスター「モフル」を進化させ、ジムバトルで競うボードゲームです。スマホのブラウザでそのまま遊べます。

**遊ぶ：** https://tm550120.github.io/mofuru-gym/

## 遊び方（モード）

URL を開くとタイトル画面が出るので、モードを選びます。ゲーム中は右上の「⌂」でタイトルに戻れます。

- **CPUと対戦**：あなた＋CPU 2人で遊びます。始める前に、あなたの手番（先攻・2番目・3番目・ランダム）と進行スピード（ゆっくり・ふつう・はやい）を選べます。
  - ゲームの状態は操作のたびに端末（localStorage）へ保存されます。リロードしたりタイトルに戻ったりしても、タイトルの「▶ 続きから」で同じ盤面・同じ状態から再開できます（リロードで盤面やサイコロを引き直すことはできません）。「新しいゲームを始める」を選ぶと保存は破棄されます。
- **フレンド対戦（オンライン）**：2〜3人で遊びます。
  1. ニックネームを入れて「部屋を作ってフレンドを招待」を押すと、5文字の部屋コードと招待リンクが出ます。
  2. フレンドはリンクを開くか、コードを入力して「参加する」を押します。
  3. 全員そろったらホストが「ゲーム開始」。「空いた席をCPUで埋める」をオンにすると、2人でもCPUを入れて3人で遊べます。手番は「ランダム」か「リストの順番」（▲で並べ替え）をホストが選びます。
  - 通信は PeerJS（WebRTC）でブラウザ同士を直接つなぎます（接続の仲介に PeerJS の無料公開サーバーを使用）。ゲームの進行はホストの端末が管理します。
  - ゲストの接続が切れたりリロードしたりしても、同じ端末ならタイトルの「▶ オンライン対戦に戻る」（または自動再接続）で自分の席に戻れます。しばらく戻らないときは、ホストが「CPUに交代」か「ゲームを終了」を選べます。
  - ホストの端末も状態を保存します。ホストがリロードした場合は、タイトルの「▶ オンライン対戦を再開（ホスト）」で同じ部屋コード・同じ盤面のまま部屋を開き直し、ゲストは自動で再接続します（約2分以内）。
  - 制限：部屋コードの取り戻しは PeerJS サーバーの都合で失敗することがあります（前の接続が残っている間は最大1分ほど再試行）。ゲストの再接続は同じブラウザ（保存されたトークン）でのみ可能で、新しい人の途中参加はできません。ネットワーク環境によってはつながらないことがあります。

## ルールの概要

- サイコロの合計と同じ数字の土地に接するジムは資源を1枚、都市は2枚もらえます。
- 資源を使って道・ジム・都市を建てます。
- 同じ資源3枚で、モフルが5つのタイプ（草・炎・風・光・岩）のどれかに進化します。
- 自分の番に「交換」から、銀行と4:1で交換するか、ほかのプレイヤーに交換を提案できます（1人または全員に提案し、最初に受けた人と成立）。CPUも損得を考えて受けたり断ったりし、ときどきCPUから提案してくることもあります。
- 7が出たら、手札が8枚以上の人は半分（切り捨て）を自分で選んで捨てます（全員が選び終わるまで待ちます）。出した人が進化済みなら相手のジムにバトルを挑めます。
- バトルはサイコロ1個＋ボーナス（進化+2、相性有利+1、都市ジム+1）。勝つと相手の資源を1枚奪い、バッジを1個もらいます。負けると進化前に戻ります。
- バッジを最初に3個集めた人がチャンピオン（+2点）。より多く集めた人が現れると移ります。
- 最長の道：自分のジム（都市）から別の自分のジム（都市）まで、自分の道だけで途切れずにつながった道が5本以上あれば対象になり、いちばん長い人が+2点（同じ長さなら先に取った人のまま）。途中に相手の建物があると途切れます。
- ジム1点、都市2点、最長の道2点、チャンピオン2点。先に10点で勝ち。
- CPUの動き・サイコロ・手番の交代は少し間を置いて表示され、直前の出来事が画面上部に表示されます（下の出来事欄をタップすると履歴）。スピードは「?」から変更できます。

タイプ相性：風 → 炎 → 草 → 岩 → 光 → 風（左が右に強い）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ゲーム本体（HTML・CSS・JavaScriptを1ファイルにまとめたもの） |
| `manifest.webmanifest` | スマホのホーム画面に追加したときの設定 |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン画像 |

## ローカルで動かす

`index.html` をブラウザで開くだけで CPU 対戦が遊べます。ビルドやインストールは不要です。オンライン対戦を試すときは `python3 -m http.server` などでローカルサーバー経由で開いてください（インターネット接続が必要です）。
