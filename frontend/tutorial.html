1どんなゲーム？

島に道とジムを建てて資源を集め、モンスター「モフル」を進化させてジムバトルで競うボードゲームです。先に10点を取った人の勝ちです。

  • 「CPUと対戦」は、あなた＋CPU 2人の3人で遊びます（フレンド対戦は2〜3人）。
  • サイコロを振ると、ジムのまわりの土地から資源がもらえます。
  • 資源を使って、道・ジム・都市を建てると点が入ります。
  • 同じ資源3枚でモフルを進化させると、相手のジムにバトルを挑めます。
点が入るもの得点
ジム1点
都市ジムを都市にする2点
最長の道ジムとジムをつなぐ道がいちばん長い人+2点
チャンピオンバトルのバッジを3個集めた人+2点

ゲームの流れ

  1. 初期配置全員がジム2つと道2本を置く
  2. 自分の番① サイコロを振る → ② 資源をもらう → ③ 建設・進化・交換 → ④ ターン終了
  3. ほかの人の番順番に同じことをくり返す（相手の番でも資源はもらえます）
  4. だれかが10点に届いたら、その人の勝ち

3ゲームを始める

まずは CPU と対戦してみましょう（ひとりで遊べます）。

  1. 「CPUと対戦」を選ぶゲームを開くとタイトル画面が出ます。🤖 CPUと対戦 をタップします。
  2. 設定を選ぶそのままでも始められます。
    • 「あなたの手番（何番目に行うか）」：先攻 2番目 3番目 ランダム
    • 「進行スピード」：ゆっくり ふつう はやい（CPUの動きや演出の速さ）
    • 「効果音（バトル）」「BGM」：オン／オフ
  3. 始める新しいゲームを始める をタップします。島が現れて、初期配置が始まります。
はじめての人は進行スピードを ゆっくり にすると、CPUの動きを目で追いやすくなります。スピードはゲーム中でも右上の ? から変えられます。
途中でやめても大丈夫「CPUと対戦」のゲームは、操作のたびに端末へ保存されます。右上の ⌂ でタイトルに戻っても、次は ▶ 続きから で同じ場面から再開できます。

4初期配置

最初に、全員がジムを2つ・道を2本ずつ置きます。ここでは資源は使いません。

  1. 1つ目のジムを置くメッセージに あなたの番：ジムを置く交差点をタップ（1つ目） と出たら、白い点が光っている交差点のどれかをタップします。
  2. つながる道を置くメッセージが あなたの番：つながる道を置く辺をタップ に変わります。いま置いたジムから伸びる白い点線のどれかをタップします。
  3. ほかの人が置くのを待つCPUも同じように置きます。順番は、手番の順に1つ目 → 逆の順に2つ目です（あなたが先攻なら、あなた → 青 → 橙 → 橙 → 青 → あなた）。
  4. 2つ目のジムと道を置く手順は1つ目と同じです（メッセージは「…（2つ目）」）。2つ目のジムを置くと、そのジムに接する土地の資源を1枚ずつもらえます（砂漠はもらえません。最大3枚）。
  5. ゲーム開始全員が置き終わると、手番が1番の人から始まります。
タップするとすぐに置かれますジム・道・都市は、盤面をタップした時点で決まります。やり直しはできないので、場所をよく見てからタップしましょう。
どこに置けばいい？ジムは、ほかのジム・都市のとなりの交差点には置けません（置ける場所だけに白い点が出ます）。おすすめの置き方は 初期配置のコツ へ。

5自分の番の流れ

  1. サイコロを振るメッセージに あなたの番：サイコロを振ろう と出ます。いちばん下の 🎲 サイコロを振る をタップします。
  2. 資源をもらうサイコロ2個の合計と同じ数字の土地に接するジムは1枚、都市は2枚、その土地の資源をもらえます。
    • 全員が対象です。相手の番でも、数字が合えばあなたも資源をもらえます。
    • もらった資源は、手札の欄が黄色く光ります。出来事には「🎲8：あなた🌲、CPU 青🧱×2」のように出ます（だれももらえないときは「収穫なし」）。
    • 7 が出たときは資源は出ません（→ 7が出たら）。
  3. 建設・進化・交換をするメッセージが 建設・進化・交換するか、ターン終了（2/10点） に変わります。できることのボタンは濃く、できないことのボタンはうすくなります。好きな順で、何回でもできます。
  4. ターン終了やることが終わったら（何もしなくてもかまいません）、ターン終了 をタップします。次の人の番になります。
最初の番は？手札が少ないので、できることはあまりありません。🌲と🧱が1枚ずつあれば道を1本置き、なければそのまま ターン終了 で大丈夫です。

相手の番のあいだ

  • メッセージは CPU 青の番… のように出て、メインボタンは押せません。CPUの動きは、画面の上のほうに少しのあいだ表示されます。
  • 相手から交換を提案されたら、受けるか断るかを選びます（→ 提案されたとき）。
  • 7 が出て手札が多いときは、捨てる資源を選びます（→ 7が出たら）。

6道・ジム・都市を建てる

自分の番で、サイコロを振ったあとに建てられます。どれも「ボタンをタップ → 盤面の白く光る場所をタップ」の2手です。

  • ボタンがうすいときは、資源が足りないか、置ける場所がありません。
  • やめるときは、同じボタンをもう一度タップします。

道　🌲🧱

  1. 道 をタップします（メッセージ：道を置く辺をタップ）。
  2. 白い点線が出た辺をタップします。
  • 自分のジム・都市・道につながる辺に置けます。相手のジムや都市を通りぬけて、その先へ伸ばすことはできません。
  • 資源が残っていれば、続けて次の辺をタップして何本でも置けます。
  • 道そのものに点はありませんが、次のジムを建てる場所へ進むために必要です。長くつなぐと「最長の道」（+2点）もねらえます。

ジム　🌲🧱🐑🌾　1点

  1. ジム をタップします（メッセージ：ジムを置く交差点をタップ）。
  2. 白い点が出た交差点をタップします。

ジムを建てられるのは、次の2つを両方みたす交差点です。

  • 自分の道がつながっている
  • となりの交差点に、建物（自分のものも相手のものも）がない

都市　🌾🌾🪨🪨🪨　2点

  1. 都市 をタップします（メッセージ：都市にするジムをタップ）。
  2. 白い輪が出た自分のジムをタップします。ジム が都市 に変わります。
  • 得点が1点 → 2点になります。
  • もらえる資源が1枚 → 2枚になります。
  • バトルを挑まれたとき、守る側のボーナスが +1 されます。

7モフルを進化させる

同じ資源3枚で、自分のモフルを進化させられます。使った資源でタイプが決まります。

  1. 進化 をタップします（サイコロの横にいる自分のモフルをタップしても開きます）。
  2. 「モフルを進化させる」の画面で、進化先を1つ選びます。3枚以上持っている資源のものだけ選べます。
  3. 進化する をタップします。
進化先使う資源強い／弱い
草リーフモフル🌲×3岩に強い炎に弱い
炎ブレイズモフル🧱×3草に強い風に弱い
風クラウドモフル🐑×3炎に強い光に弱い
光サンモフル🌾×3風に強い岩に弱い
岩ロックモフル🪨×3光に強い草に弱い

進化するとできること

  • 自分が 7 を出したとき、相手のジムにバトルを挑めます（進化前は挑めません）。
  • バトルで +2 のボーナスがつきます（挑むときも、守るときも）。
  • 相手のタイプに強ければ、さらに +1 されます。
おぼえておくこと
  • 進化しても得点は増えません。
  • 進化しているあいだは、別のタイプに変えられません。バトルに負けて進化前に戻ったら、もう一度進化できます。
  • 相手のタイプは、プレイヤー欄のモフルの頭の飾り（葉・炎・雲・星・結晶）で見分けます。

8資源を交換する

自分の番で、サイコロを振ったあとに何回でもできます。交換 をタップして、上のタブで相手を選びます。画面の上には「あなたの手札」が出て、選ぶと交換後の枚数（→）も表示されます。

銀行と交換（4枚 → 1枚）

  1. タブの 🏦 銀行と交換 をタップします。
  2. 「出す資源（同じものを4枚）」から、4枚以上持っている資源を1つ選びます。
  3. 「もらう資源（1枚）」から、ほしい資源を1つ選びます。
  4. 交換する をタップします。

プレイヤーと交換（提案する）

  1. タブの 🤝 プレイヤーと交換 をタップします。
  2. 「相手」を選びます：みんな か、相手1人（CPU 青 など）。
  3. 「あなたが出す」「あなたがほしい」の枚数を、＋ − で決めます。同じ資源を両方に入れることはできません。
  4. 提案する をタップします。「🤝 交換を提案中」の画面に、相手の返事（考え中…／断った）が出ます。
  5. だれかが受けると、すぐに交換されます（「みんな」に提案したときは、最初に受けた人と成立）。全員に断られると成立しません。待つのをやめるときは 提案を取り下げる。

提案されたとき

「🤝 CPU 青から交換の提案」のような画面が開き、「あなたがもらう」「あなたが渡す」資源が出ます。受ける か 断る をタップします。受けるとすぐに交換されます。渡す資源が足りないときは受けられません。

97が出たら

サイコロの合計が 7 のときは、資源は出ません。かわりに、次の2つが順番に起こります。

① 手札が8枚以上の人は、半分を捨てる

  • だれが 7 を出しても、手札が8枚以上の人は全員が対象です。捨てる枚数は半分（端数は切り捨て。9枚なら4枚）。
  • 自分が対象になると「🎲7！ 手札を捨てる」の画面が開きます。＋ − で捨てる資源を選び、捨てる をタップします。

② 7を出した人が進化済みなら、ジムバトルを挑める

  1. メッセージに ⚔️ 挑戦するジムをタップ（％は勝率） と出て、相手のジムと都市に白い輪と勝率が出ます。
  2. 挑戦するジムをタップします。島のどこにあるジムでも選べます。やめておくときは 挑戦しない をタップします。
  3. 「ジムバトル」の画面で、挑戦者とジム（守る側）がサイコロを1個ずつ振ります。結果を見たら OK をタップします。

自分のモフルが進化前のときは、7 を出してもバトルはありません（①だけ起こります）。

バトルの勝ち負け

サイコロ1個の目 ＋ ボーナス の合計が大きいほうの勝ち同点のときは、ジム（守る側）の勝ち
ボーナス加点つく条件
進化+2モフルが進化済み
相性+1相手のタイプに強い
都市+1挑まれたのが都市（守る側だけ）
起こること
勝った人バッジを1個もらう。相手の資源を1枚うばう（どの資源かはランダム）。
負けた人モフルが進化前に戻る。資源を1枚うばわれる。
  • 挑戦者でも守る側でも、勝ったほうがバッジをもらえます。
  • 負けても、ジムや都市がなくなることはありません。
  • 相手が 7 を出して進化済みなら、あなたのジムが挑戦されることがあります。操作はいらず、自動で守ります。

チャンピオン（+2点）

バッジを最初に3個集めた人がチャンピオンになり、+2点されます（プレイヤー欄に「王者」と出ます）。その後、チャンピオンより多くバッジを集めた人が現れると、その人に移ります。

10どうやったら勝てる？

だれかが10点に届いた瞬間に、その人の勝ちです。最初からジムが2つあるので、スタートは2点。あと8点を集めます。

点が入るもの得点必要なもの
ジム1点🌲🧱🐑🌾
都市2点ジム ＋ 🌾🌾🪨🪨🪨
最長の道+2点ジムとジムをつなぐ道が5本以上で、いちばん長い
チャンピオン+2点バッジ3個以上で、いちばん多い

10点の作り方（例）

ねらい内訳
建物だけ都市4（8点）＋ ジム2（2点）
道も使う都市3（6点）＋ ジム2（2点）＋ 最長の道（2点）
バトルも使う都市2（4点）＋ ジム2（2点）＋ 最長の道（2点）＋ チャンピオン（2点）

建物だけで10点にするには、建物が5〜6つ必要です（都市5つでも10点）。最長の道やチャンピオンの +2点を取ると、そのぶん少ない建物で届きます。

基本の進め方ジムを増やす → 都市にする → 余った資源で進化して守りを固める → 最長の道かチャンピオンで +2点。

コツ① 初期配置

  • 3つの土地に接する交差点を選びます。海ぞいや砂漠の角は、接する土地が少なくなります。
  • 点の多い数字の土地を選びます。赤い 6・8 がいちばん出やすく、次が 5・9 です。2 と 12 はめったに出ません（→ サイコロの出やすさ）。
  • 資源の種類をばらけさせます。序盤の道とジムには 🌲🧱 が欠かせません。🧱 と 🪨 の土地は3マスずつしかないので、取れるなら早めに。
  • 2つ目のジムは、もらえる資源も見て選びます。接する土地の資源を1枚ずつもらえるので、🌲と🧱がそろえば最初の番に道を置けます。
  • 道は、次にジムを建てたい交差点の方向へ。ジムは2辺先に建てるので、そこが空いているかも見ておきます。

コツ② 資源の使いみち

  • 序盤は 道 → ジム。ジムが増えるほど、接する数字が増えて、もらえる資源が増えます。
  • 🌾 と 🪨 がたまったら都市。資源が2倍、得点が+1、守りも+1 と、いいことが3つあります。
  • 手札は7枚以下で番を終える。7 は6回に1回ほど出ます。8枚以上持っていると半分を失うので、たまったら建てる・進化する・交換するで使いましょう。
  • 同じ資源が3枚余ったら進化、4枚余ったら銀行と交換、が目安です。

コツ③ 進化とバトルのタイミング

  • 進化は守りにも効きます。進化前のジムは、進化済みの相手に挑まれると相手の勝率が 72% もあります。こちらも進化済みなら 42%、さらに都市なら 28% まで下がります。
  • CPUは、勝率が 40% より低いジムには挑戦してきません。進化して都市を増やすほど、ねらわれにくくなります。
  • 挑むかどうかは％で決めます。進化前の相手のジムは 72%、都市は 58%。勝率が低いときは 挑戦しない も立派な手です。負けると進化前に戻り、資源を1枚取られ、相手にバッジを渡してしまいます。
  • バッジ3個でチャンピオン（+2点）。守って勝ってもバッジは増えます。
  • 建設に使う資源をくずしてまで急いで進化する必要はありません。同じ資源が余ったときが進化のしどきです。

コツ④ タイプ相性

  • 相手のモフルを見て、相手に強いタイプに進化すると有利です。進化の画面にも「強い：◯／弱い：◯」と出ます。
  • タイプは使う資源で決まります。ねらうタイプがあるときは、その資源を3枚ためます。
  • 自分に強いタイプの相手には、挑まないのが安全です（勝率は 28% 以下）。

コツ⑤ 最長の道

  • 数えるのは、自分のジム（都市）から、別の自分のジム（都市）まで、自分の道だけでつながった本数です。行き止まりの道は数えません。
  • 5本以上で、いちばん長い人が +2点。同じ長さでは移らないので、うばうには1本でも長くします。
  • 道のとちゅうに相手の建物があると、そこでとぎれます。
  • いまの長さは、プレイヤー欄の 🛤 で見られます。

コツ⑥ 交換

  • 銀行は 4枚 → 1枚 と高くつきます。あと1枚足りないときは、まずプレイヤーに 1枚 ↔ 1枚 で提案してみましょう。
  • CPUは、自分が得をするときだけ受けます。点数が高い人（あと少しで勝ちそうな人）からの提案は、受けてもらいにくくなります。
  • CPUから提案が来るのは、CPUが「あと1枚で建てられる」ときです。相手の ★ が高いときは、断るのも手です。

12こまったときは

ボタンがうすくて押せない

建設・進化・交換は、自分の番でサイコロを振ったあとだけできます。それでもうすいときは、資源が足りないか、置ける場所がありません（「進化」は、すでに進化済みのときも押せません）。

CPUの動きが速くて、何が起きたかわからない

右上の ? →「進行スピード」を ゆっくり にします。画面下の出来事の欄をタップすると、これまでの出来事を読み返せます。

途中でやめたい・続きから遊びたい

右上の ⌂ でタイトルに戻ります。「CPUと対戦」なら、タイトルの ▶ 続きから で再開できます。

最初からやり直したい

右上の ↻ をタップします（いまのゲームは破棄されます）。

音を消したい

右上の 🔊（効果音）と 🎵（BGM）で、それぞれオン・オフできます。

フレンドと遊びたい

タイトルの 👥 フレンド対戦（オンライン） から、ニックネームを入れて 部屋を作ってフレンドを招待 をタップします。出てきた部屋コード（5文字）か招待リンクをフレンドに送り、フレンドはコードを入れて 参加する。そろったら、部屋を作った人が ゲーム開始 をタップします。ルールと操作は「CPUと対戦」と同じです。
